SPORELINE

Quick start
-----------
1. Double-click sporeline.exe.
   A console window opens, then your browser opens to the log.
   Windows may warn about an unrecognised publisher because the file
   is not signed: More info -> Run anyway.

2. Leave the console window open while you work. Closing it stops
   Sporeline. Nothing is lost when you close it.

3. Your data goes to C:\Users\<you>\sporeline\
   Back up that folder and you have backed up everything.

Coming from mycolog
-------------------
Close mycolog, then go to Data -> Import and choose "A mycolog folder".
Nothing else to install. IDs carry over unchanged, so labels already on
your jars stay correct.

Backups
-------
Sporeline copies your log into a backups folder once a day when it
starts, and before any import. See the Settings page.
